# EXCEL_quiz

**Cell Quest** — an interactive, gamified Excel fundamentals quiz built for the workshop *Demystifying Data: A Beginner's Guide to Microsoft Excel*.

## Quick Start

- **Zero-setup offline play:** Open [`cell-quest.html`](./cell-quest.html) directly in any web browser (single self-contained file, no network calls).
- **React 18 + Vite dev server:**
  ```bash
  npm install
  npm run dev
  ```
  The complete single-file React component lives in [`src/CellQuest.jsx`](./src/CellQuest.jsx).
